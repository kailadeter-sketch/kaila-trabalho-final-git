# ☕ Cafeteria & Clube de Fidelidade

Aplicação web interativa para cafeterias com cardápio dinâmico, carrinho em tempo real e **Clube de Fidelidade gamificado**.

---

## 📌 Sobre o Projeto

O sistema combina uma experiência de e-commerce moderna com mecanismos de fidelização. Os clientes podem filtrar o cardápio por categoria ou busca, gerenciar produtos no carrinho e acompanhar seu acúmulo de pontos através de uma barra de chocolate interativa que acende a cada compra.

---

## 🚀 Funcionalidades

- **🛒 Carrinho de Compras:** Adição/remoção de itens, controle de quantidades, botão de lixeira e cálculo automático do total.
- **🔍 Filtros e Busca:** Filtragem por categorias e pesquisa de produtos por texto em tempo real.
- **🍫 Clube de Fidelidade:** Ganhe 125 pontos por pedido. A barra de chocolate avança visualmente (`gomo0` a `gomo8`) até atingir 1000 pontos e liberar uma recompensa.
